🍟 ilovefrenchfries (The Sentient Potato)

Welcome to the official repository for ilovefrenchfries, the world's first Discord bot that is a sentient, moody, and potentially waterproof potato. Powered by OpenRouter and built with Python, this bot uses a dynamic hydration system to determine how it treats your users.
🥔 Potato Mechanics

This bot isn't just an AI; it has a soul (and a lot of starch).

    Salty Phase: (0 Water) The potato is cynical, grumpy, and rude.

    Hydrated Phase: (1-50 Water) The potato is a pleasant companion.

    Ecstatic Phase: (51-99 Water) The potato is overwhelmingly sweet and grateful.

    The End: (100+ Water) The potato dies and will not respond to anyone until an admin resurrects it.

🛠 Features

    Multi-Model Intelligence: Cycles through Gemini, Llama, and DeepSeek to ensure the potato never stops talking.

    Memory: Remembers the context of the conversation.

    Health Check: Built-in web server on Port 10000 to keep Render.com services alive.

    Admin Controls: Secret commands to monitor logs and resurrect the dead.

📜 Commands

    !chat <message>: Talk to the potato.

    !ffw: Give the potato water.

    !a logs: (Admin) Check API errors.

    !a ffrsr: (Admin) Resurrect the potato.

🚀 Setup

    Clone: git clone https://github.com/compliancee/newbot-

    Install: pip install -r requirements.txt

    Env Variables: Set DISCORD_TOKEN, OPENROUTER_API_KEY, and ADMIN_ID in your host (Render/Koyeb).

    Run: python bot.py
